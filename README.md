# 100 Days of AI Agents 🚀

Learn AI engineering by building **100 practical AI bots and agents**, one project at a time — from beginner-friendly LLM apps to production-grade multi-agent systems.

## The mission

Every day adds a runnable project with:

- complete source code
- a beginner-friendly explanation
- setup and run instructions
- example inputs
- tests or smoke checks
- concepts to study
- an extension challenge

If this series helps you learn, **star the repository** and follow along.

## Learning roadmap

**Days 1–10 — Foundations**  
Prompting, structured outputs, simple bots, CLI/web interfaces, API basics.

**Days 11–25 — Tool-using agents**  
External APIs, function/tool calling, search, databases, workflows.

**Days 26–45 — RAG**  
Embeddings, chunking, retrieval, vector databases, document assistants.

**Days 46–65 — Agent systems**  
Memory, planning, state, approvals, long-running workflows.

**Days 66–80 — Multi-agent systems**  
Specialized agents, delegation, coordination, critic/reviewer patterns.

**Days 81–90 — MCP & integrations**  
MCP servers/clients, GitHub, email, calendars, databases, enterprise tools.

**Days 91–100 — Production AI**  
Evaluation, observability, guardrails, Docker, deployment, reliability, scaling.
