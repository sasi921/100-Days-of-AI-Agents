# Social post — Day 003/100

🚀 **Day 003/100 of 100 Days of AI Agents is live!**

Today we built an **AI Web Research Agent** 🔎🤖

Instead of asking an LLM to answer from memory, this agent first visits a webpage, extracts the useful content, and then reasons only over that evidence.

**URL → Fetch Tool → Clean Text → Grounded Reasoning → Answer + Source**

What we learned:

✅ Webpage fetching with Python  
✅ HTML extraction with Beautiful Soup  
✅ Grounding AI answers in external evidence  
✅ URL safety checks and failure handling  
✅ Offline testing without API calls  
✅ Deterministic fallback when no LLM key is configured

This is an important step from simple chatbots toward real research agents and, later, RAG systems.
